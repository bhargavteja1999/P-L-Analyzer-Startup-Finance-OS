Settings

• Local: fast demo, calculations in frontend/js/app.js
• SQL: production — data in backend/pnl.db → API /api/pnl, /dashboard → backend/calculations.py. Requires Flask :5000.
• MongoDB: optional — data in MongoDB pnl_analyzer → API /api/mongo/pnl, /mongo/dashboard → same engine. Set MONGO_URI env (Atlas or local) then Flask on :5000. Keeps SQLite intact.
